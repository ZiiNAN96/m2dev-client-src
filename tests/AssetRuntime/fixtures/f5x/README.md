# F5-X character fixture

Original procedural articulated test character and rigid hand prop, generated by
`../../generate_character_fixture.py` using Python 3 standard library only.
The fixture art and generated GLBs are dedicated to CC0-1.0; no third-party art.

`character.glb`: 19 skin joints, two additional real scene nodes, two opaque
textured primitives, six localized animation clips. Source front is +Z, up is +Y,
units are meters. `hand_prop.glb` is a rigid cyan test prop.

`motions.json` documents gameplay mapping. The MSA files use the existing motion
format with optional `MotionClipIndex`; the private native smoke defines loop or
one-shot behavior through the normal character APIs. Race 65000 is registered
only in the private smoke root.

Regeneration writes the GLBs and motion files alongside this README. It does not
require Blender or download any assets. A Blender export was not used to create
this fixture.

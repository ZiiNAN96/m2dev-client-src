# Milestone 13A: audit before implementation

Baseline: `f4c5ff4` (M12). Production code was clean when reviewed. This document and
the CSV are an audit snapshot, not a claim that implementation or regression has passed.

## Inventory and classification

`milestone13a-resources-before.csv` contains source statements, locations, owner,
creator, readers, reachability, category and planned action. Generated by
`tests/Renderer/AuditResources.ps1`, with reviewed resource families. Both explicit
interface names and LP aliases, wrapper getters, native creation calls, and D3DX
mesh/texture helpers are included. Test-native reference renderers are C. SDK and
build/link declarations are E, retained until M13C; vendored SDK definitions are not
client resource owners. No client Query or StateBlock allocation/use was found.

Mixed classes must not be deleted wholesale: MapOutdoor terrain streams are A,
its dynamically rendered shadow resources B; the numeric StateManager is retained.
The device's implicit backbuffer/depth surfaces remain a documented device-creation
side effect, not sources for Diligent assets. Device removal is explicitly M13B.

## Findings and minimal architecture

1. Image wrappers allocate native textures even though existing Diligent texture
   loaders already upload directly from pack bytes. Native pointer equality is
   still used by UI, font pages, tree, world and effect bridges. Static-object
   material validation reads native level metadata. Add owned neutral texture
   metadata/source storage and a binding identity; never disguise a CPU pointer as COM.
2. Preserve native getters for Legacy. Add neutral bindings to the existing
   StateManager Save/Set/Restore contract; sampler/material/numeric state logic is
   unchanged. Unbinding must clear both identities even when the native pointer
   was already null. Selected font pages and shared subimages retain their owner.
3. Common vertex/index wrappers currently require native locks. Add owned CPU
   storage for Diligent, retaining original CPU producers (including Granny skinning).
   Native pointer existence checks must become geometry-existence checks; no copy-back.
4. Terrain alpha and guild-area masks currently upload from a D3D9 locked rectangle.
   Generate the same pixels/mips from original alpha data first. Font and DIB data
   already have CPU sources. Do not insert smart pointers into memset-initialized splat PODs.
5. Tree setup must preserve strip offsets/counts and leaf LOD metadata without native
   buffers. TreeRenderBridge already captures original SpeedTree data. Snow uses CPU
   particle vertices; optional Legacy blur surfaces are not a new Diligent feature.
6. Skip startup native declarations, default primitive buffers and debug D3DX meshes
   only under the startup-selected neutral resource policy. Native D3D9 device and
   numeric state seeding remain. Selection must precede device/resource creation,
   not depend on a renderer pointer that is initialized later.

## Ownership/lifecycle contract to implement and verify

Asset/image or buffer wrappers own CPU data. Each existing Diligent subsystem owns
its own GPU handles. Legacy wrappers alone own COM GPU resources. Shared images and
saved bindings retain neutral source identity; no backend owns the other's GPU handle.
Reload/map unload clears subsystem caches and source owners; CPU source pages survive
ordinary Diligent resize. Shutdown clears saved/current bindings and subsystem handles.
Explicit creation telemetry must include every reviewed native creation entry point,
including D3DX helper allocations; implicit device surfaces reported separately.

## Verification gates (pending)

CPU texture metadata/mip/identity/lock lifetime, CPU buffer locking and bounds,
save/restore/clear ownership, generated-alpha equivalence, native creation telemetry;
Release ON/OFF, complete suites and renderer suites; isolated world and preview tests;
normal default and explicit Legacy with original packages, maps/relog/window states,
exit codes and resource release. No normal-client acceptance is inferred from old M12 tests.
